# Adrobot — Keitaro wrapper

Базовый Vue 3 + TypeScript интерфейс для тестового задания. Приложение автоматически работает в mock-режиме без `.env` или подключается к Keitaro Admin API при наличии переменных окружения.

## Запуск

```bash
npm install
npm run dev
```

Для реального Keitaro скопируйте `.env.example` в `.env` и заполните:

```dotenv
VITE_KEITARO_API_URL=https://your-tracker.example.com
VITE_KEITARO_API_KEY=your-admin-api-key
```

После изменения `.env` перезапустите Vite. URL можно указать как адрес трекера или сразу как `/admin_api/v1`.

Для проверки типов:

```bash
npm run typecheck
```

## Что уже есть

- список кампаний с поиском;
- карточка кампании с произвольным количеством потоков;
- создание кампании по названию, нескольким GEO и первому офферу;
- настройка потока: тип `regular` / `forced` / `default`, порядок, несколько GEO и fallback URL;
- добавление и удаление офферов;
- черновые изменения офферов с жёлтым статусом;
- ручной процент для закреплённого оффера, автоматическое распределение остатка и кнопка `Bring Back`;
- предупреждение и автоматическая пауза, если после сохранения не остаётся активных офферов;
- отправка накопленных изменений в mock Keitaro;
- сохранение состояния кампаний в `localStorage`;
- переключение статуса кампании;
- адаптивная вёрстка.
- автоматический выбор между mock и Keitaro API по `.env`;
- загрузка кампаний, офферов, групп, доменов и источников из Keitaro;
- создание кампании и offer-flow через Admin API;
- обновление статуса кампании и весов офферов через `PUT`.
- восстановление архивного оффера через `POST /offers/{id}/restore` перед возвратом в поток.

Код интерфейса разнесён по Vue-компонентам, логика кампаний находится в `src/composables/useCampaigns.ts`, стили собраны на Tailwind CSS.

API-клиент находится в [src/api/keitaro.ts](src/api/keitaro.ts). Ключ используется только в браузерном запросе, поэтому для production лучше проксировать Admin API через backend и не публиковать секретный ключ в клиентском bundle.

## Аудит стека относительно полного ТЗ

Сейчас это frontend-прототип: Vue 3, TypeScript, Vite и Tailwind CSS. Для полноценного соответствия ТЗ ещё нужен backend на FastAPI + SQLAlchemy с базой данных, миграциями, серверным хранением Keitaro API key и проксированием запросов к Admin API. В текущей версии вместо него используются `localStorage` в mock-режиме и прямой браузерный вызов Keitaro API при наличии `VITE_KEITARO_API_KEY`.
